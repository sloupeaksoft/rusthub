# Rust HUD для Minecraft 1.12.2 (Forge)

Полоски здоровья, еды, брони и кислорода в правом нижнем углу, как в Rust. Жажды нет.

## Сборка
1. Установи JDK 8 (обязательно 8, на новых Java Forge 1.12.2 не собирается).
2. Скачай Forge MDK 1.12.2-14.23.5.2860 с https://files.minecraftforge.net и распакуй.
3. Удали папку src из MDK и скопируй туда из этого архива: src, build.gradle, gradle.properties (с заменой).
4. В папке открой терминал и запусти:  gradlew build  (на Windows: gradlew.bat build)
5. Готовый мод: build/libs/rusthud-1.12.2-1.0.0.jar -> положи в .minecraft/mods

Проверить в игре без установки: gradlew runClient

## Что есть
- Здоровье: зелёная полоса, белый «след» урона, мигает красным при <25%, жёлтая при отравлении, серая при иссушении, золотая полоса поглощения.
- Еда: оранжевая полоса, зелёная при эффекте голода, тонкая жёлтая полоса насыщения.
- Броня и кислород (под водой).
- Настройки: Mods -> Rust HUD -> Config (угол экрана, отступы, ширина, числа 0-100 или как в ванилле, прозрачность и т.д.)
